# 隐私政策 · 外屏时钟（FoldClock）

最后更新：2026-10-13

## 一句话

**外屏时钟不联网、不收集、不上传任何信息。**

## 我们不做什么

- 不申请 `INTERNET` 权限 —— App 在系统层面就无法访问网络
- 不含统计 SDK、广告 SDK、崩溃上报 SDK
- 不读取通讯录、短信、通话记录、位置、相册、剪贴板
- 无账号体系，无云端同步

## App 实际用到的权限与数据

| 权限 / 能力 | 用途 | 数据流向 |
|---|---|---|
| `SYSTEM_ALERT_WINDOW`（悬浮窗） | 以外屏悬浮窗形式显示时钟 | 仅本机渲染，不外传 |
| `FOREGROUND_SERVICE`<br>`FOREGROUND_SERVICE_SPECIAL_USE` | 常驻监听充电与折叠状态，检查到「插电 + 合盖」时把时钟亮出来 | 无数据 |
| `POST_NOTIFICATIONS` | 前台服务所需的常驻通知条（可在系统设置中关闭） | 无数据 |
| `RECEIVE_BOOT_COMPLETED` | 开机 / 应用更新后自动恢复常驻服务 | 无数据 |
| `HIGH_SAMPLING_RATE_SENSORS` | 插电唤醒的瞬间短时高频读取铰链角度，读完立刻降回低频 | 无数据 |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | 仅用于把用户引导到系统的电池优化设置页 | 无数据 |
| `WAKE_LOCK` | 显示时钟时保持屏幕常亮 | 无数据 |
| `BIND_DREAM_SERVICE` | 作为系统屏保（Dream）运行 | 无数据 |
| 传感器 `TYPE_HINGE_ANGLE` | 读取折叠角度，用于判断是否合盖 | 仅本机实时读取，**不存储、不外传** |
| 电池 / 充电状态广播 | 判断是否处于充电状态，触发自动显示 | 仅本机使用，不存储 |

## 数据存储

App 的设置项（是否自动显示、亮度、是否防烧屏、是否显示日历等）通过 Android
`SharedPreferences` 保存于**本机 App 私有目录**。

- 不写入外部存储
- 不参与任何备份上传（App 不联网）
- 卸载 App 即全部删除

## 第三方

本 App 不集成任何第三方 SDK（无广告、无统计、无社交、无推送服务商），
也不依赖 AndroidX 等第三方运行时库。

## 儿童隐私

本 App 不含任何面向儿童的内容，也不收集任何个人信息。
